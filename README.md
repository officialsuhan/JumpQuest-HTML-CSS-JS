# 🎮 JumpQuest — 2D Platformer Game

**JumpQuest** is a browser-based 2D platformer game built using HTML, CSS, JavaScript, and HTML5 Canvas. The project explores game development fundamentals through player movement, jumping, platform interactions, and canvas-based rendering.

## ✨ Features

- 🎮 **2D Platformer Gameplay** — Control a character in a platform-based game.
- 🦘 **Jump Mechanics** — Jump to navigate the game environment.
- 🧱 **Platform Interaction** — Move around and land on platforms.
- 🎨 **Canvas Rendering** — Draw and update game elements using HTML5 Canvas.
- ⚡ **Real-Time Updates** — Animate gameplay using JavaScript.
- 🌐 **Browser-Based** — Play directly in a compatible web browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas

## 📂 Project Structure

```text
JumpQuest/
├── index.html

└── script.js
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Follow the on-screen instructions, if provided, to start playing.

No installation or build tools are required for basic local use.

## 🎯 Project Purpose

JumpQuest was created to practice JavaScript game development, animation, keyboard input, collision detection, and drawing interactive game scenes with HTML5 Canvas.
